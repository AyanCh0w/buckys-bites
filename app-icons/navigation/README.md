# Navigation icons

Five original line icons on a 28 × 28 grid, with rounded caps and joins. Default stroke: 1.8. Selected stroke: 2.1. Colors come from the app theme.

Edit the SVG sources here, then run `node scripts/generate-navigation-icons.mjs` to regenerate the bundled PNG assets at 1×, 2×, and 3×.

Home uses an arched doorway; Menu combines a plate, fork, and knife; Nutrition shows three chart segments; Ratings holds a star inside a speech bubble; Me is a circular profile.
